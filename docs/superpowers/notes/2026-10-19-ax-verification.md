# AX 가정 검증 (2026-10-19)

카카오톡 Mac 앱, 실제 계정에서 확인. 대화 내용은 기록하지 않음.

| 가정 | 결과 | 비고 |
|---|---|---|
| 1. 방 열기 | 성공 (더블클릭 폴백) | 목록 행은 AX 액션 없음, 셀은 `AXShowMenu`만. 화면 밖 행은 목록 스크롤바를 행 위치 비율로 옮겨 보이게 한 뒤 더블클릭. |
| 2. 스크롤로 과거 로드 | 성공 | 스크롤바 `AXValue` 설정 가능. 테이블은 불러온 행을 계속 유지(가상화 아님). **맨 위(0)에 닿을 때만** 과거 행이 추가 로드되고 값이 0.05 근처로 튐. |
| 3. 내 메시지 가로 위치 | 성공 (규칙 보정) | 나와의 채팅: 본문 30개 모두 창 중심 오른쪽. 여러 장 사진 행은 이미지가 좌우로 나란해 "가장 큰 이미지" 기준이면 왼쪽으로 오판 → 이미지 영역 합집합 기준으로 보정. |

## 계획 반영
- Task 1: 더블클릭은 목록 영역 안에 보이는 행에만 (`visibleFrame(of:)`).
- Task 3: 미디어 행의 위치 판별은 non-badge 이미지 frame 합집합.
- Task 5: 새 행이 없으면 간격을 두 배로(최대 1.0), 간격 1.0에서도 새 행이 없을 때만 맨 위 도달로 판단.
